# 35. 로컬 개발도구와 검증 방법

## 현재 준비된 도구

- 프로젝트 전용 .NET SDK 10.0.302: C:\Project\.tools\dotnet
- 프로젝트 전용 NuGet 캐시: C:\Project\.nuget
- Agent 빌드 스크립트: agent-windows\tools\build-agent.ps1
- Java는 현재 시스템 JDK 17만 있으며 서버 기준 Java 21 설치가 남아 있다.
- Visual Studio C++ Build Tools, Windows SDK, WDK가 없어 KMDF 드라이버 빌드는 아직 불가능하다.

## Agent 개발 명령

PowerShell에서 다음처럼 실행한다.

    cd C:\Project
    .\agent-windows\tools\build-agent.ps1 restore
    .\agent-windows\tools\build-agent.ps1 build
    .\agent-windows\tools\build-agent.ps1 test

스크립트는 사용자 홈 권한 문제를 피하도록 DOTNET_CLI_HOME, NuGet, APPDATA를 프로젝트 전용 경로로 격리한다.
