# 39. 온라인·오프라인 아이콘 및 로컬 로그 저장정책

## 트레이 아이콘 상태

| 아이콘 | 연결 상태 | 정책 동작 |
|---|---|---|
| 초록 | 서버 온라인 | 현재 서버 정책 적용 |
| 노랑 | 서버 오프라인, 과거 정상 정책 존재 | 마지막 정상 정책 계속 적용 |
| 회색 | 서버 최초 미연결 또는 정책 미수신 | 탐지와 로그만 수행 |
| 빨강 | 정책 손상·만료 또는 드라이버 오류 | 보호 모드 또는 오류 상태 |

UI Helper는 로그인 세션별 트레이 아이콘을 유지한다. 서비스가 Heartbeat 성공 또는 실패를 감지하면 LocalSystem 인증 named pipe로 상태를 전달한다. UI를 새로 시작한 직후에는 회색으로 시작하며 다음 Heartbeat 시 실제 상태로 변경된다.

트레이 메뉴의 상태 보기를 선택하면 현재 상태와 색상 의미를 확인할 수 있다.

## 오프라인 정책

- 정상 정책을 한 번도 받지 않음: DETECT_ONLY
- 마지막 정상 정책이 있음: 해당 정책을 로컬에서 계속 적용
- 정책 캐시 삭제·손상·만료: 필수 HID를 제외하고 fail-closed
- 온라인 복구: 서명·Hash·버전 검증 후 최신 정책으로 교체
- 서버 연결이 끊겨도 로컬 큐에 이벤트를 계속 적재

## 로컬 저장 위치

기본 루트:

    C:\ProgramData\YoungOne\MediaControl

파일 구성:

| 경로 | 내용 |
|---|---|
| logs\agent-YYYYMMDD.log | Agent 운영 JSON 로그 |
| logs\agent-YYYYMMDD-NN.log | 일일 파일 크기 초과 시 분할 로그 |
| risk-queue.db | 미전송 위험 이벤트 SQLite 큐 |
| risk-queue.db-wal / shm | SQLite WAL 실행 파일 |
| policy.cache | DPAPI 보호 정책 캐시 |
| activation.latch | 최초 제어 활성화 이력 |
| credential.dat | DPAPI 보호 Agent 인증정보 |
| identity.dat | DPAPI 보호 Installation ID |

## 로그 보존

- 운영로그 기본 보존: 30일
- 파일 한 개 최대 크기: 20 MiB
- 날짜 변경 또는 크기 초과 시 분할
- JSON Lines 형식으로 timestamp, level, category, eventId, message, exception 기록
- 위험 이벤트는 서버 전송 성공 전까지 risk-queue.db에 보존
- SQLite connection pooling을 끄고 각 작업 종료 시 파일 핸들을 해제해 백업·업그레이드를 방해하지 않음

비밀번호, Agent Key, 정책 서명키, 원문 USB Serial은 운영로그에 기록하지 않는다.

## 검증

Agent/UI 전체 빌드 성공. 단위 테스트 12개 성공, 실패 0. 운영 JSON 로그 파일 생성, SQLite 이벤트 적재·건수·파일 핸들 해제를 검증했다.
