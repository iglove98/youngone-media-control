## 0.10 인사·디렉터리 다중연동
AD/LDAP, SCIM, REST, JDBC View, CSV/SFTP, 메시지 큐, 수동 업로드를 Connector SPI로 지원한다. 입력은 내부 person UUID로 정규화하며 사번·로그인 ID만으로 자동 병합하지 않는다. 퇴사·휴직은 즉시 사용자 정책을 비활성화하되 단말 기본 제어를 유지한다. 상세 기준은 `32-인사-디렉터리-다중연동-설계.md`를 따른다.

## 0.19.0 제거 승인 배포

WiX는 Agent, UserUi, AgentCtl의 win-x64 publish 디렉터리를 각각 입력받는다. 제품 전체 제거 시 업그레이드가 아니면 AgentCtl 승인 소비가 성공해야 StopServices 이후 제거가 진행된다. 운영 배포 전 WiX SDK 7 빌드, 서명, 무승인/만료/정상승인/업그레이드 네 경우의 VM 테스트가 필수다.
